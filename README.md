# Project Siddhi — The Final Sprint

**One Team. One Last Sprint. Infinite Memories.**

A responsive, single-page farewell experience for Siddhi, built with plain HTML, CSS and JavaScript. No build step or framework required.

## Run locally
Open `index.html` in any modern browser.

## Deploy to Netlify
1. Open Netlify and choose **Add new site → Deploy manually**.
2. Drag the project folder into the deploy area, or connect this GitHub repository for continuous deployment.
3. If connecting the repository, use the repository root as the publish directory. No build command is required.

## Before the farewell
- Replace the abstract portal on the hero with Siddhi's photograph (optional).
- Replace the sample quotes with real team inside jokes.
- Add actual team photographs and memories.
- Collect the 25–30 colleague messages.
- The message form is currently front-end demo only: messages appear in the current browser session and are not shared across devices. For a shared wall, connect Firebase, Supabase or a hosted form service.

## Customize
All site content and styling are in `index.html`. Search for the section headings, `FAREWELL-` ticket IDs, or sample quote text to update them.
